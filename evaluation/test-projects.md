# Test Projects

## 1. Community scholarship nonprofit

Primary conversion: scholarship application or donation, depending page. Test program eligibility, event, donation, governance, and impact architecture. Media is limited and must not be fabricated.

## 2. Youth football and basketball organization

Primary conversion: program registration. Test multi-sport IA, schedule clarity, age/skill pathways, coaching proof, merchandise, action photography, and parent-oriented mobile use.

## 3. Local roofing or construction company

Primary conversion: estimate request or phone call. Test service/location architecture, project proof, trust claims, before/after media, emergency versus planned work, and local SEO.

## Optional 4. Women’s fashion boutique

Primary conversion: purchase. Test category and product pages, size/variant controls, product photography, shipping/returns, boutique identity, and mobile product UX.

For each project, prepare a fixed content-and-assets packet, baseline run, system run, screenshots, audits, rubric scores, and retrospective.
