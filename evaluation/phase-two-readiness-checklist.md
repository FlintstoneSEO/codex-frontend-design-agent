# Phase 2 Readiness Checklist

Do not begin Phase 2 until all mandatory items pass.

- [ ] At least three sample projects completed
- [ ] Baseline and system variants scored
- [ ] Skills activate consistently and missed activations are documented
- [ ] Three art directions are structurally different
- [ ] Final designs show materially less repetition
- [ ] Page specifications include implementation-ready composition maps
- [ ] Eyebrow frequency, repeated introductions, alignment runs, silhouettes, archetype diversity, and hierarchy sources are measured
- [ ] Composition variety is content-driven rather than arbitrary
- [ ] CMS schemas do not force universal eyebrow / heading / description / button sections
- [ ] Rubric identifies issues reviewers agree are real
- [ ] Mobile composition preserves hierarchy rather than merely stacking desktop columns
- [ ] Projects remain compositionally distinctive without losing brand cohesion
- [ ] Accessibility blockers are detected
- [ ] SEO is present in page specifications before coding
- [ ] Performance budgets catch regressions without blocking reasonable media
- [ ] No system-induced fabricated facts
- [ ] Context loading does not overwhelm Codex
- [ ] A project can be completed without manually repeating global rules
- [ ] Unnecessary complexity and redundant files have been removed
- [ ] At least one skill or standard revision cycle completed from test evidence
