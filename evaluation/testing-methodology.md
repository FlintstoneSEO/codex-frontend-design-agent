# Testing Methodology

## Experiment design

For each sample project:

1. Freeze the same verified brief, content set, media set, stack, and time box.
2. Create a baseline using the existing general prompt without this system.
3. Create a treatment using this repository and required workflow.
4. Do not let the treatment see the baseline score before completion.
5. Render the same routes and viewports.
6. Score both with the 100-point rubric using at least two reviewers where possible.
7. Run accessibility, SEO, performance, anti-template, and composition repetition checks on full-page desktop and mobile screenshots.
8. Record time, context loaded, number of clarification cycles, defects, and rework.
9. Compare outcomes and identify overhead.

## Measures

- Total rubric score and category deltas
- Automatic failures
- Number of repeated generic patterns
- Eyebrow / kicker frequency as a share of major sections
- Count and longest run of equivalent section-introduction patterns
- Longest run of the same primary alignment
- Repeated component silhouettes and repeated media ratios without purpose
- Number and semantic fit of composition archetypes and hierarchy sources
- Mobile composition quality: preserved hierarchy versus generic stacking
- Cross-project distinctiveness under the same evaluation set
- Mobile defects
- Accessibility defects by severity
- SEO requirements present before implementation
- LCP/CLS/TBT laboratory diagnostics and field data when available
- Number of fabricated or unsupported facts
- Design decision traceability
- Context size and workflow completion time
- Skill activation precision and missed activations

## Validity controls

- Same content and assets
- Same technical constraints
- Same target routes
- Blind or rubric-led review where practical
- Record deviations
- Do not infer conversion lift without analytics or controlled testing
- Do not reward arbitrary uniqueness. Penalize both mechanical repetition and chaotic or semantically unsupported variation.
- Evaluate the target balance: cohesive brand system + varied page rhythm + content-driven composition.

## Composition evidence protocol

For each tested route, inventory every major section with its eyebrow presence, introduction formula, primary alignment, silhouette, density, media ratio, hierarchy source, composition archetype, and mobile transformation. Reviewers must cite the inventory and full-page screenshots when scoring composition.

Compare projects for distinctive composition only after controlling for their different content and user intent. A shared archetype is not a defect when the content relationship genuinely calls for it.
