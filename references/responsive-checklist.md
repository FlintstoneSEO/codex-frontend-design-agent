# Responsive Checklist

Review 375, 390, 768, 1024, and 1440px, plus 320px reflow and text zoom.

- [ ] Reading order remains logical
- [ ] No horizontal page overflow
- [ ] Navigation is task-appropriate
- [ ] Heading wraps are intentional
- [ ] Body measure remains readable
- [ ] Images preserve focal subject
- [ ] Tables/comparisons have an accessible adaptation
- [ ] Controls remain labelled and reachable
- [ ] Sticky UI does not cover content
- [ ] Tap targets are usable
- [ ] Desktop whitespace does not become mobile dead space
- [ ] Repeated stacking does not create an excessively long undifferentiated page
- [ ] Landscape and zoom states tested
