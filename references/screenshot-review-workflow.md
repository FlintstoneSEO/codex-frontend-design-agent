# Screenshot Review Workflow

Render each priority page at 375, 390, 768, 1024, and 1440 pixels.

## Inspect

- Above-the-fold composition
- Reading and focus order
- Alignment and container logic
- Visual hierarchy
- Section rhythm and density
- Image crop and focal point
- Button prominence and competition
- Navigation state
- Heading wrapping
- Repetition and generic patterns
- Overflow and clipped effects
- Empty space
- Mobile ergonomics
- Brand and industry appropriateness

## Issue format

| Severity | Element | Viewport | Problem | Exact change | Reason | Expected outcome | Verification |
|---|---|---:|---|---|---|---|---|

Bad: “Improve spacing.”

Good: “At 390px, reduce the gap between the program title and schedule from 40px to 20–24px and keep the age/location metadata attached to the title. The current gap separates one decision unit and pushes registration below the first screen.”
