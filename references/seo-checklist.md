# SEO Checklist

- [ ] Page has one clear search and user purpose
- [ ] Unique descriptive URL, title, meta description, and H1
- [ ] Logical headings and semantic HTML
- [ ] Crawlable descriptive internal links
- [ ] Canonical URL and correct robots directive
- [ ] Included in sitemap if indexable
- [ ] Images have useful filenames, dimensions, and purpose-based alt
- [ ] Open Graph metadata and social image
- [ ] Breadcrumbs for hierarchical pages
- [ ] Structured data matches visible verified content
- [ ] No fabricated schema properties
- [ ] Local pages represent real locations or differentiated service areas
- [ ] Product/category content is unique and decision-useful
- [ ] Facets, pagination, search, and duplicate URLs are controlled
- [ ] Critical content renders reliably
- [ ] 404, redirects, canonicalization, and status codes tested
